# CONTENT WORKFLOW

## Порядок работы со статьями

1. Найти подходящую категорию согласно BRAND_BOOK.md.
2. Проверить структуру хранения в REGISTRY_STRUCTURE.md.
3. Использовать ARTICLE_TEMPLATE.md при создании статьи.
4. Не создавать новые категории без согласования.
5. После утверждения статьи обновить реестр.
6. При изменении процесса обновить документацию в docs/.
