# ID_RULES

## Правила идентификаторов

- Каждая статья получает уникальный артикул.
- Артикулы не переиспользуются.
- Все связанные материалы (дизайны, обложки, сторис) используют идентификатор статьи.
- Поиск осуществляется сначала по артикулу, затем по названию.

## Принципы
- Единая система идентификаторов для всего проекта VIRVOX.
- Любые изменения правил фиксируются в документации.
