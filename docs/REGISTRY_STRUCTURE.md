# REGISTRY_STRUCTURE

## Общие принципы

Реестр является единым источником данных о статьях проекта VIRVOX.

## Алгоритм работы
1. Проверить документы в папке docs/.
2. Найти подходящую категорию согласно BRAND_BOOK.md.
3. Проверить существование статьи в реестре.
4. При создании использовать ARTICLE_TEMPLATE.md.
5. После утверждения обновить реестр и связанные документы.

## Правила
- Не создавать новые категории без согласования.
- Любые изменения структуры фиксировать в документации.
