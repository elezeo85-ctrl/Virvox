# VIRVOX Logo System

**Version:** 1.0
**Status:** Approved baseline

## Purpose

This document defines the role of the VIRVOX logo system and its relationship to registered visual assets.

## Core principle

The logo is a stable brand identifier. It should remain visually consistent across outputs and should not be redrawn or altered ad hoc.

## Registered logo assets

- `BA-LOGO-001` — Monogram VX. Canva Design ID: `DAHQGdFhl5k`. Status: Pending visual confirmation.
- `BA-LOGO-002` — Full Logo with Descriptor. Canva Design ID: `DAHQIOXVfks`. Status: Approved.

## Usage

Use the full logo when the brand needs explicit identification. Use the monogram where the context and available space make a compact mark more appropriate.

## Protection

Do not stretch, distort, rotate, recolor outside the approved visual system, or recreate the logo manually.

## Source

Editable logo artwork is maintained in Canva. GitHub stores registration metadata and usage rules.
