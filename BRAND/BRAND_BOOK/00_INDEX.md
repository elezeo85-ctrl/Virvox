# VIRVOX Brand Book v1.0

## Purpose

This directory contains the modular, versioned Brand Book for VIRVOX.

## Structure

- `00_INDEX.md` — Brand Book navigation.
- `01_DNA.md` — brand DNA and philosophy.
- `02_NAMING.md` — naming and ID conventions.
- `03_LOGO.md` — logo system and usage principles.
- `04_VISUAL_SYSTEM.md` — visual identity system.
- `05_CATEGORY_SYSTEM.md` — ten-category content system.
- `06_COVER_SYSTEM.md` — cover construction principles.
- `07_ASSET_LIBRARY.md` — asset library rules.
- `08_CANVA_REGISTRY.md` — Canva source references.
- `09_GITHUB_STRUCTURE.md` — relationship between Brand Book and repository architecture.
- `10_FILE_REFERENCE.md` — description of Brand Book files.
- `CHANGELOG.md` — Brand Book change history.

## Governance

The Brand Book is modular. Each chapter has a focused responsibility and may be updated independently. Approved changes must be versioned and recorded in the relevant changelog.

GitHub stores the documentation and metadata; Canva stores editable visual design files.
