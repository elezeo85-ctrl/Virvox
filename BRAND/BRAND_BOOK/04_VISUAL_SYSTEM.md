# VIRVOX Visual System

**Version:** 1.0
**Status:** Approved baseline

## Purpose

The VIRVOX visual system creates a consistent visual language across articles, covers, stories, reels, and other content formats.

## System components

- Logo system.
- Category marker system.
- Typography.
- Color system.
- Background treatment.
- Layout grid and safe zones.
- Content hierarchy.
- Cover and social-format rules.

## Modular principle

The system is built from reusable components. Components should be reused through approved assets and templates rather than recreated independently for each publication.

## Category marker

Category identity is represented through the approved category system and master asset `BA-CAT-001`. The category changes the editorial label and associated treatment while preserving the overall VIRVOX visual language.

## Typography and color

Exact production values must be maintained in the visual identity specifications and approved design masters. Do not invent replacement values when the authoritative design source is unavailable.

## Consistency rule

A new design may introduce a new composition only when it remains compatible with the approved logo, typography, color, category, spacing, and hierarchy rules.

## Source relationship

Canva is the editable visual source of truth. GitHub documents the system and registers the corresponding assets.
