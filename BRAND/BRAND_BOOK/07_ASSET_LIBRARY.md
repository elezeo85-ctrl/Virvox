# VIRVOX Asset Library

## Purpose

The asset library provides a controlled way to identify, locate, and reuse approved brand assets.

## Registration model

Each important asset should have:

- Internal asset ID.
- Descriptive name.
- Type.
- Status.
- Version.
- Canva Design ID when applicable.
- GitHub registry path.
- Related Brand Book rules.

## Preservation

Approved assets are never silently deleted. If replaced, the previous asset remains documented as deprecated or superseded.

## Source relationship

GitHub records the metadata and relationships. Canva remains the editable design source.
