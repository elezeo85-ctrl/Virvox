# VIRVOX Naming and ID Conventions

## Purpose

Stable naming and IDs make the project searchable, versionable, and resilient to changes in display names.

## ID prefixes

- `BA-` — Brand Asset.
- `CAT-` — Content Category.
- `ART-` — Article.
- `TPL-` — Template.
- `DOC-` — Document.

## Asset naming

Use concise, descriptive names. Prefer stable semantic names over names tied to temporary campaigns or dates.

## Category naming

User-facing category names are stored in the Category Registry. Internal IDs remain stable.

## Versioning

Use `MAJOR.MINOR.PATCH` where practical. A new ID is not required for a normal version update when the underlying object remains the same.
