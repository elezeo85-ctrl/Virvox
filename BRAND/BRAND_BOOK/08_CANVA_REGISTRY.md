## Purpose

This document connects registered VIRVOX objects in GitHub with their editable Canva design sources.

## Governance

GitHub stores the stable internal ID, description, status, and Canva Design ID. Canva stores the editable design itself.

## Important rule

A Canva Design ID must not be invented or guessed. If an ID cannot be verified, the registry entry must be marked pending until confirmed.

## Future fields

Where useful, registry records may also include:

- Canva URL.
- Design version.
- Last verified date.
- Format.
- Intended use.
- Related asset IDs.

## Synchronization

When a production design changes in Canva, its GitHub registry record should be reviewed and updated if the change affects the approved version, purpose, or source reference.
