# CONTENT WORKFLOW

## Purpose

This document describes the canonical workflow for creating, approving, registering, and rendering VIRVOX content.

## Workflow

```text
Category
  ↓
Check PROJECT_RULES and relevant registries
  ↓
Select applicable template
  ↓
Create content object
  ↓
Assign or confirm unique ID
  ↓
Review and approve
  ↓
Register approved content
  ↓
Attach related assets and Canva IDs where applicable
  ↓
Render using approved template and brand rules
  ↓
Verify output and registry consistency
```

## Rules

1. Check existing categories, templates, IDs, and registries before creating new objects.
2. Draft content is not treated as approved content until approval is recorded according to project workflow.
3. Approved articles must be represented by the canonical article object structure and linked to the article registry.
4. Visual assets must be linked to the appropriate asset/design registry and preserve Canva Design IDs when applicable.
5. Rendering must follow the approved brand system and applicable template.
6. Any state-changing workflow must leave the relevant registry and documentation consistent.

## Source of truth

- Project rules and architecture: `DOCS/`
- Brand rules: `BRAND/`
- Registry data: `REGISTRY/`
- Content objects: `CONTENT/`
- Templates: `TEMPLATES/`
- Operational system and automation: `SYSTEM/`
- Editable visual designs: Canva
