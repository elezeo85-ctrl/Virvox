# VIRVOX Version History

## v1.0 — Knowledge System Foundation

**Status:** Approved baseline

Established the first formal project documentation architecture, including:

- project manifest;
- project rules;
- project map;
- architecture documentation;
- file reference;
- knowledge base;
- decision log;
- roadmap;
- version history;
- changelog.

Established the principle that GitHub is the source of truth for project knowledge and Canva is the source of truth for editable visual design.

Established the ten-category system and stable category IDs.

## v1.1 — Documentation Architecture Normalization

**Status:** Approved

Established and consolidated the canonical project documentation layer under `DOCS/`, including:

- canonical documentation index;
- AI operational entry point;
- AI command reference;
- stable ID rules;
- content lifecycle workflow;
- canonical article template;
- registry architecture documentation.

Updated the architecture model to distinguish the governance/documentation layer from the production flow and clarified the hierarchy:

`PROJECT MANIFEST → PROJECT RULES → BRAND / SYSTEM RULES → ARCHITECTURE + DOCUMENTATION → REGISTRIES → TEMPLATES → CONTENT OBJECTS → OUTPUTS`.

Updated the file reference to document the canonical `DOCS/` structure and the six authoritative registry files.

Established `DOCS/00_INDEX.md` as the canonical documentation entry point and consolidated project-wide documentation under the uppercase `DOCS/` tree.
