## Documentation authority

`DOCS/` is the single canonical project-wide documentation tree. Operational guidance previously maintained in a separate lowercase `docs/` tree is consolidated here. New project-wide rules and instructions must be added to the appropriate document under `DOCS/` rather than creating a parallel authoritative documentation tree.
