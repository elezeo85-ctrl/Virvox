# VIRVOX Knowledge Base

## Purpose

This document preserves durable knowledge that should survive individual conversations and remain available to future project work.

## Core knowledge

### Source-of-truth separation

GitHub is the source of truth for structured project knowledge, documentation, registries, architecture, rules, and history. Canva is the source of truth for editable visual design files.

### Stable identifiers

Objects should be identified by stable internal IDs. Names are presentation metadata and may evolve under controlled change.

### Category system

The approved category system contains ten categories:

- `CAT-001` — Разбор мифов
- `CAT-002` — Взгляд женщины
- `CAT-003` — Мужской взгляд
- `CAT-004` — Из жизни
- `CAT-005` — Практика
- `CAT-006` — Исследование
- `CAT-007` — Размышление
- `CAT-008` — Диалог
- `CAT-009` — Ответы на вопросы
- `CAT-010` — Мудрые мысли

The master category design is `BA-CAT-001`.

### Asset registration

Visual assets should be registered with internal IDs and Canva Design IDs. Approved assets should not be silently replaced or deleted.

### Documentation architecture

The project documentation is intentionally modular. Separate documents make it possible to update one area without rewriting the entire knowledge base.

## Preservation rule

When a new important rule or discovery is made, it should be added here or to the most appropriate authoritative document. The chat history is not considered a sufficient permanent archive by itself.
