# ID RULES

## Purpose

Identifiers provide stable identity and traceability across the VIRVOX system.

## Rules

1. Every registered object must have a unique identifier appropriate to its object type.
2. An identifier must never be reused for a different object.
3. Related objects should reference their parent or source object ID where the architecture defines such a relationship.
4. Search should prefer exact ID matching before title or keyword matching.
5. IDs must remain stable when an object is edited or rendered into a new output.
6. A new ID must be created only when a genuinely new object is created, not when an existing object is revised.
7. Canva Design IDs must be preserved for visual assets created in Canva and recorded in the appropriate registry.
8. Registry records must remain consistent with the files and assets they identify.

## Article IDs

Article IDs identify article objects and are assigned through the article registry. The article ID remains stable across revisions and related assets should reference it where applicable.

## Validation

Before creating a new object:

- search the relevant registry;
- confirm that the proposed ID is unused;
- confirm that no existing object already represents the same identity;
- register the object immediately after approval according to the applicable workflow.
