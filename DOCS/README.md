# VIRVOX — Project Documentation

This directory contains the official project documentation and knowledge system for VIRVOX.

GitHub is the source of truth for project documentation, registries, architecture, rules, decisions, and version history. Canva is the source of truth for editable visual design assets.

## Documentation map

- `00_INDEX.md` — master navigation for project documentation.
- `PROJECT_MANIFEST.md` — project constitution and high-level principles.
- `PROJECT_RULES.md` — mandatory operating and governance rules.
- `PROJECT_MAP.md` — map of the VIRVOX ecosystem and relationships between systems.
- `ARCHITECTURE.md` — repository and system architecture.
- `FILE_REFERENCE.md` — passport and reference guide for project files and directories.
- `KNOWLEDGE_BASE.md` — durable knowledge, standards, and lessons that must not be lost.
- `DECISIONS.md` — record of important architectural and project decisions.
- `ROADMAP.md` — planned development stages.
- `VERSION_HISTORY.md` — major version history.
- `CHANGELOG.md` — chronological documentation changes.

## Core principle

No approved knowledge, asset, or decision is discarded without trace. Changes are versioned and documented so that previous states can be reconstructed from Git history.
